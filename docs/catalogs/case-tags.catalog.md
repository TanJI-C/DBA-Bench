# Case citation tags

每个 bounded Case 与 Persistent Scenario 携带一个稳定的论文引用短码。短码是冻结的:
新增 Case 只能领取其 (system, category) 组内的下一个空闲序号;不允许改号、重排或复用。
bounded 短码的唯一事实源是 `src/scenarios/case_tags.py`(键为 `(scenario_id, case_id)`,
经 `tests/test_case_tags.py` 与本清单双向同步);persistent 短码写在各 spec YAML 的
`citation_tag` 字段。Benchmark run 表在 `citation_tag` 列输出短码。

`basic` 演示类场景(`demo`、`cpu_overload`、`container_pause`、`tidb_demo`)没有 contract
文档,对应行以 `—` 标注;其余场景链接到其当前 contract。
