# TiDB Cloud Serverless Limitations and Quotas

TiDB Cloud Serverless works with almost all workloads that TiDB supports, but there are some feature differences between TiDB Self-Managed or TiDB Cloud Dedicated clusters and TiDB Cloud Serverless clusters. This document describes the limitations of TiDB Cloud Serverless.

We are constantly filling in the feature gaps between TiDB Cloud Serverless and TiDB Cloud Dedicated. If you require these features or capabilities in the gap, use [TiDB Cloud Dedicated](https://docs.pingcap.com/tidb/stable/tidb-cloud/select-cluster-tier#tidb-cloud-dedicated) or [contact us](https://www.pingcap.com/contact-us/?from=en) for a feature request.
## Limitations
### Audit logs

- [Database audit logging](https://docs.pingcap.com/tidb/stable/tidb-cloud/tidb-cloud-auditing) is currently unavailable.
### Connection

- Only [Public Endpoint](https://docs.pingcap.com/tidb/stable/tidb-cloud/connect-via-standard-connection-serverless) and [Private Endpoint](https://docs.pingcap.com/tidb/stable/tidb-cloud/set-up-private-endpoint-connections-serverless) can be used. You cannot use [VPC Peering](https://docs.pingcap.com/tidb/stable/tidb-cloud/set-up-vpc-peering-connections) to connect to TiDB Cloud Serverless clusters. 
- No [IP Access list](https://docs.pingcap.com/tidb/stable/tidb-cloud/configure-ip-access-list) support.
### Encryption

- Data persisted in your TiDB Cloud Serverless cluster is encrypted using the encryption tool provided by the cloud provider that manages your cluster. For [scalable clusters](https://docs.pingcap.com/tidb/stable/tidb-cloud/select-cluster-tier#scalable-cluster-plan), an optional second layer of encryption is available during the cluster creation process, providing an additional level of security beyond the default encryption at rest.
- Using [customer-managed encryption keys (CMEK)](https://docs.pingcap.com/tidb/stable/tidb-cloud/tidb-cloud-encrypt-cmek) is currently unavailable.
### Maintenance window

- [Maintenance window](https://docs.pingcap.com/tidb/stable/tidb-cloud/configure-maintenance-window) is currently unavailable.
### Monitoring and diagnosis

- [Third-party Monitoring integrations](https://docs.pingcap.com/tidb/stable/tidb-cloud/third-party-monitoring-integrations) are currently unavailable.
- [Built-in Alerting](https://docs.pingcap.com/tidb/stable/tidb-cloud/monitor-built-in-alerting) is currently unavailable.
- [Key Visualizer](https://docs.pingcap.com/tidb/stable/tidb-cloud/tune-performance#key-visualizer) is currently unavailable.
- [Index Insight](https://docs.pingcap.com/tidb/stable/tidb-cloud/tune-performance#index-insight-beta) is currently unavailable.
### Self-service upgrades

- TiDB Cloud Serverless is a fully managed deployment of TiDB. Major and minor version upgrades of TiDB Cloud Serverless are handled by TiDB Cloud and therefore cannot be initiated by users.
### Stream data

- [Changefeed](https://docs.pingcap.com/tidb/stable/tidb-cloud/changefeed-overview) is not supported for TiDB Cloud Serverless currently.
- [Data Migration](https://docs.pingcap.com/tidb/stable/tidb-cloud/migrate-from-mysql-using-data-migration) is not supported for TiDB Cloud Serverless currently.
### Time to live (TTL)

- In TiDB Cloud Serverless, the [`TTL_JOB_INTERVAL`](https://docs.pingcap.com/tidb/stable/time-to-live#ttl-job) attribute for a table is fixed at `15m` and cannot be modified. This means that TiDB Cloud Serverless schedules a background job every 15 minutes to clean up expired data.
### Others

- Transaction can not last longer than 30 minutes.
- For more details about SQL limitations, refer to [Limited SQL Features](https://docs.pingcap.com/tidb/stable/tidb-cloud/limited-sql-features).
