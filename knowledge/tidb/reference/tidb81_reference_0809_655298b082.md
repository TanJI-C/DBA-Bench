# Overview of Key Concepts

This document provides an overview of the key concepts in [TiDB Cloud](https://www.pingcap.com/tidb-cloud/). Understanding these concepts helps you better use TiDB Cloud features and capabilities.
## Architecture

TiDB Cloud is built on a cloud-native distributed architecture that separates computing from storage, enabling elastic scaling and high availability. [Learn more about TiDB Cloud architecture](https://docs.pingcap.com/tidb/stable/tidb-cloud/architecture-concepts).
## Database schema

TiDB Cloud enables you to organize and structure your data using objects such as databases, tables, columns, indexes, and constraints. It also supports advanced features such as temporary tables, vector indexes, and cached tables. [Learn more about database schema](https://docs.pingcap.com/tidb/stable/tidb-cloud/database-schema-concepts).
## Transactions

TiDB provides complete distributed transactions, and the model has some optimizations on the basis of [Google Percolator](https://research.google.com/pubs/pub36726.html). [Learn more about transactions](https://docs.pingcap.com/tidb/stable/tidb-cloud/transaction-concepts).
## SQL

TiDB is highly compatible with the MySQL protocol and the common features and syntax of MySQL 5.7 and MySQL 8.0. [Learn more about SQL in TiDB Cloud](https://docs.pingcap.com/tidb/stable/tidb-cloud/sql-concepts).
## AI features

The AI features in TiDB Cloud enable you to fully leverage advanced technologies for data exploration, search, and integration. [Learn more about AI features](https://docs.pingcap.com/tidb/stable/tidb-cloud/ai-feature-concepts).
## Data Service (Beta)

Data Service enables you to access TiDB Cloud data via an HTTPS request using a custom API endpoint. [Learn more about Data Service](https://docs.pingcap.com/tidb/stable/tidb-cloud/data-service-concepts).
## Scalability

TiDB Cloud Dedicated lets you adjust its compute and storage resources separately to match your data volume or workload changes. [Learn more about scalability](https://docs.pingcap.com/tidb/stable/tidb-cloud/scalability-concepts).
## High availability

TiDB Cloud ensures high availability in both TiDB Cloud Serverless and TiDB Cloud Dedicated clusters:

- [High Availability in TiDB Cloud Serverless](https://docs.pingcap.com/tidb/stable/tidb-cloud/serverless-high-availability)
- [High Availability in TiDB Cloud Dedicated](https://docs.pingcap.com/tidb/stable/tidb-cloud/high-availability-with-multi-az)
## Monitoring

TiDB Cloud provides comprehensive monitoring capabilities for cluster performance and health. [Learn more about monitoring](https://docs.pingcap.com/tidb/stable/tidb-cloud/monitoring-concepts).
## Data streaming

TiDB Cloud lets you stream data changes from your TiDB Cluster to other systems such as Kafka, MySQL, and object storage. [Learn more about data streaming](https://docs.pingcap.com/tidb/stable/tidb-cloud/data-streaming-concepts).
## Backup & Restore

TiDB Cloud offers automated backup solutions and point-in-time recovery (PITR) capabilities. [Learn more about backup and restore](https://docs.pingcap.com/tidb/stable/tidb-cloud/backup-and-restore-concepts).
## Security

TiDB Cloud provides a robust and flexible security framework designed to protect data, enforce access control, and meet modern compliance standards. [Learn more about security](https://docs.pingcap.com/tidb/stable/tidb-cloud/security-concepts).
